<h1 align="center">Contributing to CityHealth</h1>

Thank you for your interest in CityHealth! This project was developed as a Master's thesis (PFE) demonstrating a complete healthcare infrastructure platform for Algeria.

<h2 align="center">Project Status</h2>

This is primarily a **showcase repository** for academic purposes. The live platforms are actively maintained, but this repository serves as documentation and reference.

<h2 align="center">Repository Structure</h2>

This is a **monorepo** containing:
- ✅ **Complete source code** for Browser Extension and AI MCP Server
- 📄 **Documentation** for Web Platform, Mobile Application, and REST API
- 📊 **Architecture diagrams** and system documentation
- 🖼️ **Screenshots** and visual documentation
- 📝 **Complete thesis report** (PDF in docs folder)

<h2 align="center">How to Explore</h2>

### 1. Browser Extension
```bash
cd browser-extension
npm install
npm run dev
```

### 2. AI MCP Server
```bash
cd ai-mcp-server
npm install
cp .env.example .env
# Edit .env with your Supabase credentials
npm start
```

### 3. Documentation
- **Architecture**: `docs/architecture/`
- **Features**: `docs/features/`
- **UML Diagrams**: `docs/uml/`
- **Development Journey**: `docs/journey/product-journey.md`
